# ugv_webots

Webots R2025a simulation of the Waveshare UGV Rover for ROS 2 Humble. It publishes the same
topics and frames as `ugv_gazebo` and reuses the SLAM and Nav2 configuration of `ugv_slam`
and `ugv_nav`.

Full documentation: [docs/SIMULATOR.md](../../../docs/SIMULATOR.md). Setup per operating system:
[docs/setup/](../../../docs/setup/).

## Launch files

| Launch | Starts |
|---|---|
| `ugv_webots.launch.py` | Webots, driver, ros2_control controllers, robot_state_publisher, scan normalizer, OAK point cloud, optional RViz |
| `gmapping.launch.py`, `cartographer.launch.py`, `slam_toolbox.launch.py` | Simulation + 2D SLAM + RViz |
| `nav.launch.py` | Simulation + Nav2 (AMCL on `maps/apartment.yaml` by default) |
| `slam_nav.launch.py` | Simulation + SLAM and Nav2 together |

Common arguments: `world:=apartment.wbt|empty_arena.wbt`, `use_rviz:=true|false`,
`headless:=true|false`.

## Executables

| `ros2 run ugv_webots ...` | Purpose |
|---|---|
| `scan_normalizer` | Republishes the Webots lidar scan in the layout of the real LD19 driver (started by the launch file) |
| `motion_check` | Drives 1 m and one full turn, prints commanded vs `/odom` vs ground truth |
| `rtf_meter` | Measures the real-time factor from `/clock` |
| `print_urdf` | Prints the URDF the simulation uses (`--upstream-only` for the urdf2webots input) |

## Files

* `protos/UgvRover.proto`: generated by `scripts/generate_proto.py` from
  `ugv_description`. Regenerate, do not edit.
* `resource/webots_extras.urdf`: Webots sensor plugins and the `webots_ros2_control` hardware,
  appended to the upstream URDF by `ugv_webots/description.py`.
* `resource/ros2_control.yaml`: `diffdrive_controller`, `joint_state_broadcaster`,
  `pt_joint_position_controller`.
* `worlds/`: `apartment.wbt` (default) and `empty_arena.wbt`.
* `maps/apartment.*`: map of the apartment world, made with gmapping.
* `ugv_webots/ground_truth.py`: Webots plugin publishing the true pose on
  `/ugv_webots/ground_truth`.
* `ugv_webots/webots_host.py`: finds Webots across WSL or a VM (`UGV_WEBOTS_HOST` overrides).
